## 💻 Developer CLI Terminal Reference

Access the built-in terminal anywhere on the site by clicking the **`>_`** icon or launching the terminal modal:

| Command | Action / Response |
| :--- | :--- |
| `whoami` | Displays developer bio, role, current status, and location dossier |
| `projects` | Lists all flagship production releases and architectural specs |
| `skills` | Ranks top technical proficiencies with competence breakdown |
| `certs` | Outputs accredited certifications, credentials, and hackathon victories |
| `contact` / `hire` | Prints direct transmission endpoints (Email, LinkedIn, GitHub) |
| `tudum` | Triggers the synthesized cinematic audio chime |
| `clear` | Clears the terminal screen buffer |

## ⚡ Local Development Setup

Clone the repository and spin up the local development server:

```bash
# 1. Clone the repository
git clone https://github.com/Himarghya/Portfolio.git

# 2. Enter project directory
cd Portfolio

# 3. Install dependencies
npm install

# 4. Launch Vite dev server
npm run dev

# 5. Build for production
npm run build
```
