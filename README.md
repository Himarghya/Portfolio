## 💻 Developer CLI Terminal Commands

Launch the terminal inside the portfolio (`>_` button or keyboard shortcut) to run interactive commands:

| Command | Output / Description |
| :--- | :--- |
| `whoami` | Displays developer bio, role, and location dossier |
| `projects` | Lists all live streaming releases & system architectures |
| `skills` | Ranks top 10 technologies with match percentages |
| `certs` | Outputs accredited certifications & hackathon podium finishes |
| `contact` / `hire` | Prints direct transmission endpoints (Email, GitHub, LinkedIn) |
| `tudum` | Plays synthesized 4K HDR audio indicator |
| `clear` | Flushes the terminal viewport |

## ⚡ Quickstart & Local Setup

```bash
# 1. Clone repository
git clone https://github.com/Himarghya/Portfolio.git

# 2. Navigate into project folder
cd Portfolio

# 3. Install dependencies
npm install

# 4. Start local Vite development server
npm run dev

# 5. Build optimized production bundle
npm run build
```
