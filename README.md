## 🌟 Key Highlights & Features

- **⚡ 60FPS Cinematic Intro**: Hardware-accelerated GPU 3D transform reveal with synthesized audio chime.
- **🪐 Interactive 3D Geospatial Console**: Real-time Three.js obsidian holographic globe with Fibonacci node constellations and cursor physics tracking.
- **🎥 Instant Hover Video Previews**: Built-in video playback for core systems (**Polaris** & **VarshaNet**) with seamless resource management.
- **✨ Dynamic Neural Constellation Background**: Mouse-reactive HTML5 particle canvas with magnetic crimson laser beams and chromatic spotlight aura.
- **💎 Dark Frosted Glassmorphism**: High-contrast specular glass panels with `#E50914` accents, responsive layout, and mobile drawer navigation.
- **💻 Interactive Cyber Terminal**: Built-in CLI shell emulator with command auto-completion and dossier inspection.

## ⚡ Quickstart & Local Setup

```bash
# 1. Clone the repository
git clone https://github.com/Himarghya/Portfolio.git

# 2. Navigate to project root
cd Portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev

# 5. Build for production
npm run build
```
